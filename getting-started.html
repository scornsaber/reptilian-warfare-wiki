REPTILIAN WARFARE / GETTING STARTED

Your first steps

Pick a world, learn the controls, and decide who you want to become.

Install the mod

The 3.0.0 release was built with these versions:

ComponentVersion
Minecraft1.21.5
NeoForge21.5.98
GeckoLib for NeoForge5.0-alpha2 for Minecraft 1.21.5
Java21
  1. Set up a Minecraft 1.21.5 profile with NeoForge.
  2. Put the Reptilian Warfare 3.0.0 JAR and the matching GeckoLib JAR in that profile’s mods folder.
  3. Start the NeoForge profile. Check that Reptilian Warfare appears in the mod list.
  4. For multiplayer, install matching mod versions on the server and on each player’s client.

This wiki contains player guides. The mod download is supplied separately.

Before choosing a side

You begin as a normal human. Explore first: becoming a hunter or unlocking a beast form commits you to that path in normal play.

The kaiju path

Find a Tide Altar in an ocean domain or an Ember Altar in a gila cave domain. Interact with it using an empty hand to choose that species.

The hunter path

Bring a reptilian eye to a Hunter King in a human settlement. Accept the eye-for-chestplate trade to join the hunters.

Choose carefully

New beast unlocks come only from altars. After choosing one species, the other altar refuses you. Hunters cannot unlock beast forms. Forms already unlocked in older saves are preserved.

Useful first checks

  • Press H to see your progression or hunter standing.
  • Check Minecraft’s Controls menu if a mod key conflicts with another binding.
  • Normal human visitors can approach kaiju domain residents peacefully. Attacking them starts a fight; hunters and rival kaiju are enemies.
  • Radiation patches are dangerous to ordinary humans. Getting to an altar peacefully does not make the terrain safe.

Continuing an older world

Back up the save before updating. Previously unlocked forms stay unlocked, including saves that already had both species. Explore new chunks to find the new world generation. Existing structures stay where they were.
